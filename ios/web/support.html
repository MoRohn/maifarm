Frequently Asked Questions

Where is my API key stored?

Your API key is stored securely in the iOS Keychain on your device. It is never transmitted to our servers. Only your device has access to your API key.

Which AI providers are supported?

MaiFarm supports Claude (Anthropic), GPT (OpenAI), Grok, and local models via Ollama. You can switch between providers at any time in Settings.

How do I get an API key?

Visit your AI provider's website to create an account and generate an API key:

  • Claude: console.anthropic.com
  • OpenAI: platform.openai.com
  • Grok: x.ai

Does MaiFarm work offline?

MaiFarm can continue working while offline. Tasks will be queued and executed when you reconnect. Your existing data remains accessible.

How do I delete my account?

Go to Settings > Account > Delete Account. This will permanently delete your account and all associated data. This action cannot be undone.

Is my data synced across devices?

If you enable iCloud sync, your tasks and preferences will sync across your Apple devices. You can disable this in Settings > Sync.

Why is my farm taking a long time?

Farm duration depends on task complexity and your AI provider's response time. You can monitor progress in real-time. If a farm seems stuck, try stopping and recreating it.

How do I report a bug?

Email us at bugs@maifarm.app with a description of the issue, steps to reproduce, and your device information.

Troubleshooting

App won't start or crashes

  • Force quit the app and relaunch
  • Restart your device
  • Update to the latest version from the App Store
  • Delete and reinstall the app (note: this will clear local data)

API key not working

  • Verify the key is correct (no extra spaces)
  • Check that your API account has credits/quota
  • Try regenerating a new key from your provider
  • Ensure you're using the right key for the selected provider

Tasks not completing

  • Check your internet connection
  • Verify your API key is valid and has remaining quota
  • Try a simpler task to test connectivity
  • Check the app's network status indicator

Tip: Most issues can be resolved by ensuring you have a stable internet connection and a valid API key with sufficient quota.
