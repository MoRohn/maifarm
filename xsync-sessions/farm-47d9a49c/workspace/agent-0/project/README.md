# Healthy Dinners Grocery List

A comprehensive grocery list application for planning healthy dinners.

## Features
- Organized by food categories
- Multiple meal options support
- Nutritionally balanced selections
- Easy-to-use checklist format

## Structure
- `src/` - Source code
- `data/` - Grocery list data
- `docs/` - Documentation

## Usage
Open `index.html` in a browser to view the interactive grocery list.
