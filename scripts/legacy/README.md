# Legacy Scripts

Scripts in this directory are preserved for historical reference and manual recoveries. They rely on the pre-2.0 repository layout (`src/`, `server/`, `shared/`) and are not wired into the current build or npm tooling. Run them only if you understand their expectations and adapt the paths to the new structure when necessary.

For day-to-day maintenance use the scripts at `scripts/` and the documented commands in `README.md` and `SETUP.md`.
