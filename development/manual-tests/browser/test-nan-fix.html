Testing NaN Fixes in MaiFarm

Fixed Issues:

  1. HarvestHeadlineSummary.tsx
    • Line 24: Fixed division by zero when calculating success rate (harvest.summary.totalTasks could be 0)
    • Line 185: Fixed division by zero when calculating Tasks/Minute (harvest.summary.duration could be 0)
    • Added null checks for harvest.quality.overallScore
  2. HarvestAnalytics.tsx
    • Line 75: Fixed success rate calculation with zero check
    • Line 245: Fixed duration display with null check
  3. SaveAsSeedModal.tsx
    • Line 51: Fixed success rate calculation in YAML comment
    • Line 52: Fixed duration calculation in YAML comment
    • Line 138: Fixed duration display in modal
  4. harvestService.ts
    • Added WebSocket connection checks before emitting events
    • Prevents "WebSocket not connected" warnings for harvest:join and harvest:leave events
    • Also fixed for terminal request and command events

Root Causes:

  • Division by zero when harvest.summary.totalTasks is 0
  • Division by zero when harvest.summary.duration is 0
  • Missing null/undefined checks for numeric values
  • WebSocket events being emitted before connection is established

Solution Applied:

  • Added ternary operators to check for zero values before division
  • Return 0 as default when denominator is zero
  • Added null coalescing for potentially undefined values
  • Check websocketService.connected before emitting events

The application should now properly handle edge cases where harvest data might have zero values, preventing NaN from being passed as children to React components.
