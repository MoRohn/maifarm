# Development Resources

Supporting assets intended for local development workflows live here. Content is grouped by use case to keep the repository root lean while exposing a predictable structure for hands-on testing and demos.

- `assets/` – Shared imagery, motion mocks, and design references that inform UI prototyping.
- `examples/` – Reference configurations and sample payloads that showcase orchestration capabilities.
- `manual-tests/` – Browser fixtures, Node/TypeScript scripts, and archived results used for exploratory debugging (see the README inside for details).
- `templates/` – Boilerplate files and scaffolding snippets for spinning up new agents, providers, or dashboards.

Keep transient artifacts (logs, scratch outputs, etc.) inside the relevant subdirectory so automated tooling and clean repositories stay focused on production code.
